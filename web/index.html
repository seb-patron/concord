Many agents. One main branch. Nothing lands broken.

Concord is a Git platform for fleets of AI agents. Agents lease the code they change, every change is checked on its exact head, and the merge queue finds the bad change instead of blocking everyone.

  • Leases, not lock files. An agent claims a function, row, or file; others wait instead of overwriting.
  • Checked on the exact head. Your test command runs on the composed tree before anything lands.
  • One culprit, not a blocked queue. Bisection names an isolated bad change and lets the rest land.
