Interpretation: “wrongly lost” counts intended non-abandoned runs that lost the original hold during a disconnect or sleep; it is an availability proxy, not a claim that expiry violated the protocol. Dead-holder minutes sum only the abandoned-run lease time after abandonment and before expiry. Renew calls count client heartbeats; server phase extensions are not RPCs. A run is complete only if it lands without abandonment or lapse.

Reproduction used `node --experimental-strip-types test.ts` because Bun is absent and the sandbox blocked npx/tsx startup. Seed and inputs are fixed in test.ts. This model has no real network, agents, queue service, or clock implementation.
